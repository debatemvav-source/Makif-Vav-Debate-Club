🛠️ מדריך הניהול המלא לאתר מועדון הדיבייט

איזה כיף שהאתר באוויר ומתעדכן!
האתר בנוי בשילוב של שתי מערכות כדי להקל עליך ככל האפשר:

  1. התמונות נמשכות אוטומטית מ-Google Drive.
  2. הטקסטים והמבנה נשלטים דרך קובץ ה-content.json ב-GitHub.

הנה כל מה שצריך לדעת כדי לנהל את האתר בצורה שוטפת.

🖼️ ניהול תמונות (דרך Google Drive)

כל התמונות באתר נמשכות ישירות מתיקיית הדרייב הראשית שלך. בתוך התיקייה הראשית צריכות להיות התיקיות הבאות:

  • Logo (תמונה אחת ללוגו)
  • Hero (תמונה אחת לרקע העליון בעמוד הראשי)
  • About (3 תמונות לפסקאות האודות)
  • Gallery (כמה תמונות שתרצה שיתחלפו בגלריה)
  • Teams (תמונות של כל הנבחרות)
  • Staff (תמונות של צוות המועדון)
💡 טיפ: איך לסדר את התמונות?
הסקריפט מושך את התמונות ומסדר אותן לפי השם של הקובץ.
  • בנבחרות (Teams): הסקריפט מסדר מהגבוה לנמוך (כדי שהשנה האחרונה תהיה ראשונה). קרא לתמונות לפי שנת המחזור, למשל: 2025.jpg, 2024.jpg, 2023.jpg.
  • בצוות ובאודות (Staff / About): הסקריפט מסדר מהנמוך לגבוה. לכן, כדי שהתמונות יופיעו בסדר הנכון (מנטורית, קפטן, סיניורים, ג'וניורים), מומלץ לקרוא לקבצים במספרים: 1.jpg למנטורית, 2.jpg לקפטן, 3.jpg לסיניורים, 4.jpg לג'וניורים.

כדי להחליף תמונה, פשוט תמחק את התמונה הישנה מהתיקייה בדרייב ותעלה את החדשה באותו שם. האתר יתעדכן בפעם הבאה שירעננו אותו!

📝 ניהול טקסטים (דרך GitHub)

כל הטקסטים באתר נמצאים בקובץ אחד שנקרא content.json בתוך המאגר שלך ב-GitHub.
כדי לערוך אותו: היכנס לקובץ ב-GitHub ולחץ על סמל העיפרון ✏️ (בצד ימין למעלה). לאחר שסיימת, לחץ על Commit changes.

⚠️ כלל ברזל בעריכת JSON!
  1. טקסט חייב להיות תמיד עטוף במרכאות. (למשל: "הטקסט שלי")
  2. אם יש רשימה של פריטים (כמו כמה שאלות או כמה חוויות), חייב להיות פסיק , בין פריט לפריט, אבל אסור שיהיה פסיק אחרי הפריט האחרון ברשימה!

1. 👥 צוות המועדון (Staff)

כדי לשנות את המילים של המנטורית או הקפטן, רד לתחתית הקובץ לאזור ה-"staff". תראה שם בלוקים כמו זה:

"mentor": {
  "title": "מנטורית המועדון",
  "image": "",
  "word": "כאן נכנס הטקסט המרגש של המנטורית..."
}

פשוט שנה את הטקסט שבתוך השורה של "word". המרכאות הענקיות יתווספו אוטומטית באתר!

2. ❓ שאלות ותשובות (FAQ)

כדי להוסיף שאלה חדשה, חפש את "faq" ואז את "questions". תעתיק את הבלוק של השאלה האחרונה, תוסיף פסיק אחריה, ותדביק:

{
  "q": "השאלה הישנה...",
  "a": "התשובה הישנה..."
},
{
  "q": "השאלה החדשה שלך?",
  "a": "התשובה החדשה שלך!"
}

3. ⭐ חוויות התלמידים (Testimonials)

בדיוק כמו בשאלות, גם כאן יש רשימה. חפש את "testimonials" ואז "items". אם תרצה להוסיף חוויה, העתק את אחד הבלוקים והוסף אותו:

{
  "name": "שם התלמיד",
  "quote": "החוויה שלו כאן..."
}

4. 🏆 נבחרות העבר (Teams)

תחת "teams" > "items" יש רשימה של 11 בלוקים, אחד לכל נבחרת. אם תרצה בעתיד להוסיף את נבחרת 2026, פשוט תוסיף בלוק ראשון ברשימה (אל תשכח את הפסיק בין הבלוק הראשון לשני):

"teams": {
  "title": "הנבחרות שלנו",
  "items": [
    {
      "years": "2026",
      "image": "",
      "description": "נבחרת מחזור ל\"ד - תיאור..."
    },
    {
      "years": "2025",
      "image": "",
      "description": "נבחרת מחזור ל\"ג - תיאור..."
    }
    // ... שאר הנבחרות
  ]
}

שימו לב: ה-image תמיד נשאר ריק "" כי התמונה נמשכת מהדרייב.

מתי אראה את השינויים?
כל שמירה (Commit) ב-GitHub לוקחת בין דקה לשלוש דקות עד שהיא מתעדכנת ברשת. תמונות בדרייב עשויות לקחת כמה דקות להתעדכן בגלל המטמון (Cache) של גוגל.
